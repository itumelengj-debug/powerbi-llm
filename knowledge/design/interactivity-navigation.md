# Interactivity and navigation

## Tooltip pages
A report page with Page information > Allow use as tooltip and Canvas settings > Type: Tooltip (320 x 240)
shows a small report on hover. Use it for detail that would otherwise clutter the main page.

## Drillthrough
Add fields to a detail page's Drillthrough well; users right-click a data point and drill through, and a
back button is added. Keep landing pages light and put row-level tables behind drillthrough.

## Navigation and view switching
Page navigator buttons (Insert > Buttons > Navigator > Page navigator) give an app-like menu; bookmarks
with buttons switch between views of the same page (chart or table, absolute or %). Bookmarks capture
page state, so create them in Desktop.

## User-chosen axes and measures
Field parameters (Modeling > New parameter > Fields) let users switch the axis or the measure of a visual
from a slicer - one flexible visual instead of several similar ones. Calculation groups do the same for
time comparisons (current, prior year, YoY %).

## Interactions and slicers
Set Format > Edit interactions deliberately (filter, highlight or none) so a click does what the reader
expects. Sync slicers across pages where the same field applies. On DirectQuery models add an Apply
button to slicers.

## Mobile layout
View > Mobile layout arranges the same visuals for phones; put KPIs first, one chart per screen width.
